# corsosub.wellnesstown.it

Landing page del corso sub primo livello di Wellness Town.

## Stack

Single-file HTML standalone. Nessuna build, nessuna dipendenza locale.

- Tailwind via CDN
- Cormorant Garamond + Inter (Google Fonts)
- Lucide icons via CDN
- Form prova gratuita con 4 turni (12-13 giugno 2026)

## Deploy

Il file è servito da GitHub Pages dal branch `main`, root `/`.
URL pubblico GitHub Pages: https://markcus78.github.io/corsosub/

Mockup di anteprima per validazione UI/UX. Da portare poi sullo scheletro AAS (shadcn + Tailwind v3) per la versione di produzione con tracking Meta Pixel + webhook Keap.
